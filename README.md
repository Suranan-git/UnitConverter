# Unit Converter

A simple Java web application for converting length units.

## Project Page

https://github.com/Suranan-git/UnitConverter

## Technologies Used

- Java
- JSP
- Jakarta Servlet
- Maven
- Apache Tomcat
- NetBeans

## Features

- Convert length units easily
- Simple and user-friendly interface
- Java Servlet-based web application
- Supports multiple length units

## Supported Units

- Millimeter (mm)
- Centimeter (cm)
- Meter (m)
- Kilometer (km)
- Inch
- Foot
- Yard
- Mile

## How to Run

1. Open the project in NetBeans.
2. Start Apache Tomcat.
3. Run the Unit Converter project.
4. Open the browser.
5. Go to:

http://localhost:8080/
