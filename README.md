# Unit Converter

## Project URL

https://github.com/Suranan-git/UnitConverter

## Description

A simple Java web application for converting length units.

## Technologies Used

- Java
- JSP
- Jakarta Servlet
- Maven
- Apache Tomcat
- NetBeans

## Features

- Millimeter conversion
- Centimeter conversion
- Meter conversion
- Kilometer conversion
- Inch conversion
- Foot conversion
- Yard conversion
- Mile conversion

## How to Run

1. Open the project in NetBeans.
2. Start Apache Tomcat.
3. Run the project.
4. Open http://localhost:8080/
